# CartPole 基础策略梯度：逐行讲解

对照同目录的 `train.py` 阅读。先看 25–75 行，这就是学习算法的核心。图表代码单独在 `plot_results.py`，无需先学习画图。

## 如何运行

在本目录执行：

```sh
./.venv/bin/python train.py
```

默认训练 2000 局，学习率 0.01，折扣因子 0.95，再用固定模型测试 500 局。训练和测试都按网络概率抽样动作。模型和结果保存在 `results/`。如果需要重新安装环境：

```sh
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python train.py
```

## 数据流

每一步：四个状态数 → 网络 → 左右动作概率 → 抽取动作 → 环境返回奖励和下一状态。

一局结束：所有真实奖励 → 倒着算每步 G → 与每步 log 概率相乘 → 损失相加 → 反向传播 → Adam 更新参数。

`log_probs[t]`、`rewards[t]`、`returns[t]` 对应同一步。`G` 是环境奖励算出的值，代码没有人为给动作指定回报。

### 为什么第 64 行多了 gamma^t？

前面对话先用 `-G_t * log(p_t)` 解释了每步损失的核心。这里严格对应作业的目标 `J = E[r_0 + gamma*r_1 + gamma²*r_2 + ...]`，采用 `-sum(gamma^t * G_t * log(p_t))`。

`G_t` 里面的折扣从第 t 步重新计起，而 `gamma^t` 表示从整局第 0 步走到第 t 步的折扣。二者作用不同。例如第二步的 G 是 `r_1 + gamma*r_2 + ...`，再乘 `gamma` 后，就与整局中的 `gamma*r_1 + gamma²*r_2 + ...` 对齐。这不是 baseline，也没有对回报做标准化。
